# Hikayat Bisu — Phase 0 foundation and Phase 1 arena

This static Phaser 3.90.0 ES-module project has no bundler or build step. It starts at Title, then enters the empty Balai Cerita camp. The existing Phase 1 grey-box arena is accessible from camp. The game stores the name, look, language, tier, settings and bench checkpoint locally. It has no accounts, analytics or tracking.

## GitHub Pages

Merge the Phase 0 pull request into `main`. In repository Settings → Pages select **Deploy from a branch**, branch **main**, folder **/(root)**, then save. Open the resulting `https://<owner>.github.io/<repo>/` link in a current phone browser in landscape. Add to Home Screen for fullscreen display. Load once while online to cache the Phaser module and project files, then reload offline.

For a local preview, run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000/`. Direct `file://` loading cannot import JSON modules or register a service worker.

Enter a hero name, select a look, language and tier, then continue to camp. Tap **Arena Ujian** to play the earlier combat test. In the arena: left stick to move and aim, Tetak to attack, Lompat to jump, Langkah to dodge and Tangkis to parry. Tap **Susun Butang** to move and resize buttons. Three fingers toggle FPS, pointer count, scene and debug unlock flags. The content validator is at `/tools/validate.html`.

The `/src/stages/stage1` through `stage6` folders are reserved for later phases. There are no stage mechanics in Phase 0. Placeholder sound is generated by WebAudio in the existing arena; `/audio` is reserved for later replacement files.
