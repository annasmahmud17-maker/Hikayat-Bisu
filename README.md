# Hikayat Bisu — Phase 1 combat test

Open `index.html` through a local HTTP server or GitHub Pages. Landscape phone browser recommended. No build step. On a computer, `python3 -m http.server 8000` serves the root. GitHub Pages may be enabled from main/root after review and merge.

The left thumb stick moves and aims. Right-side buttons attack, jump, dodge, parry and heal. Tap Susun Butang to drag buttons; tap one then use size controls. Rupa cycles three looks; Kulit cycles skin shades. Keyboard: A/D or arrows move, W/S aim, Space jump, J slash, K parry, L dodge, H heal. Controller: left stick, south jump, west slash, east parry, north dodge.

Only Phase 1 is implemented. Bench saves Kata and settings. Other ability flags stay locked. The game uses Phaser 3.90.0 from jsDelivr and caches it for subsequent offline use. All visuals and audio are procedural.
